# ApexLoad App Store screenshots

Ready-to-upload screenshots generated from the seven approved iPhone captures.

## Required in the current App Store Connect form

- `screenshots/iphone_6_5/`: upload all seven files under **iPhone → 6.5" Display**.
- `screenshots/ipad_13/`: upload all seven files under **iPad → 13" Display**.

## Optional current-device set

- `screenshots/iphone_6_9/`: upload under **iPhone → 6.9" Display** if that slot is available.

## Output specifications

- iPhone 6.5": 1242 × 2688 PNG
- iPhone 6.9": 1290 × 2796 PNG
- iPad 13": 2064 × 2752 PNG
- All images are RGB with no alpha channel.

The iPhone screenshots preserve the original app UI edge-to-edge. The iPad set
places the unmodified iPhone capture in a presentation frame so the UI is not
stretched or misrepresented.
